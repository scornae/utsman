# Utsman

เว็บบอกเวลาละหมาดทั่วประเทศไทยระดับตำบล ครอบคลุม 77 จังหวัด 928 อำเภอ 7,436 ตำบล

คำนวณในเครื่องของผู้ใช้ทั้งหมด ไม่ต้องมีเซิร์ฟเวอร์ ไฟล์เดียวจบ (`index.html`)

**ใช้งาน:** https://scornae.github.io/utsman/

## ทำอะไรได้

- ค้นหาตำบล หรือกดปุ่ม GPS เพื่อใช้ตำแหน่งปัจจุบัน
- เวลาละหมาดวันนี้ ดูวันก่อนหน้า/ถัดไป (ปัดนิ้วบนมือถือได้)
- ตารางรายเดือน เลือกเดือนและปีได้
- เลือกมัซฮับสำหรับเวลาอัสริ (ชาฟีอี / ฮานาฟี)
- 5 ธีม สลับได้ด้วยจุดมุมขวาบน เว็บจำธีมและตำบลล่าสุดไว้ในเครื่อง
- ธีมแรกมีโหมดกลางวัน/กลางคืนอัตโนมัติ ตามเวลาพระอาทิตย์ขึ้นและตกของตำบลที่เลือก

## วิธีคำนวณ

- ใช้ไลบรารี [adhan](https://github.com/batoulapps/adhan-js) ด้วยเกณฑ์มุมดวงอาทิตย์ใต้ขอบฟ้า ซุบฮิ 20° และอิชาอ์ 18°
- ทุกเวลาบวกเผื่อ 15 วินาทีแล้วปัดขึ้นเป็นนาที
- ปรับเทียบกับตารางเวลาปฏิบัติศาสนกิจของสำนักจุฬาราชมนตรี 3 จังหวัดตลอดทั้งปี
- ใช้พิกัดจุดกลางของแต่ละตำบล ผู้ที่อยู่ปลายตำบลอาจต่างจากจุดอ้างอิงได้ราว 40 วินาที ตำบลที่ใหญ่ที่สุดราว 90 วินาที (ใช้ปุ่ม GPS เพื่อความใกล้เคียงมากขึ้น)

> เว็บนี้ไม่ใช่ประกาศอย่างเป็นทางการของสำนักจุฬาราชมนตรี แต่เป็นการคำนวณทางดาราศาสตร์เพื่อให้สอดคล้องกับเวลาทางการมากที่สุด

## ความเป็นส่วนตัว

- ไม่มีบัญชี ไม่มีระบบวิเคราะห์ผู้ใช้ ไม่ส่งข้อมูลตำแหน่งไปที่ใด
- ตำบลที่เลือก ธีม และโหมดเก็บอยู่ในเบราว์เซอร์ของผู้ใช้เท่านั้น
- ตำแหน่ง GPS ใช้คำนวณในเครื่อง ไม่ถูกส่งออก
- ฟอนต์โหลดจาก Google Fonts ตามธีมที่เปิด (หากโหลดไม่ได้จะใช้ฟอนต์สำรองของเครื่อง)

## รันในเครื่อง

ดาวน์โหลด `index.html` แล้วเปิดด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร
